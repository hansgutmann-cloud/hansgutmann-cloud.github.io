DESIGN / IMPLEMENTATION

Nothing here
is a pretend machine.

A small website, made from a few carefully chosen primitives.

01 / A continuous thread

The hero is a (2,3) torus knot. Its centerline is c(t) = ((2 + cos 3t) cos 2t, (2 + cos 3t) sin 2t, sin 3t), with t ∈ [0,2π]. A narrow tube is swept around this curve using a local orthonormal frame. The surface grid follows the parameterization.

The renderer first tries native WebGPU with a WGSL shader. If that path is unavailable, it tries WebGL2 with GLSL; if both fail, the pre-rendered SVG remains. There are no external models, textures, fonts, or graphics libraries. Motion pauses when off-screen, in a hidden tab, or when reduced motion is requested.

02 / A compiler, not a recording

The compiler is written in dependency-free JavaScript. It parses a deliberately bounded, pure i32 expression language, lowers to SSA-like IR, optimizes, emits a valid Wasm binary, and instantiates it inside a dedicated Worker. The Wasm module imports nothing, exports only compute, and contains no loops or memory access. If Wasm is unavailable, an explicitly labeled interpreter fallback preserves the example.

03 / Models with boundaries

The S₃ table is constructed from permutations; all 216 associativity triples are checked. The cache is a cold, direct-mapped teaching model. The scheduler is round robin with zero context-switch cost. These models illustrate mechanisms; they do not benchmark the visitor’s hardware.

04 / Interface before spectacle

Real links work without JavaScript. Notes have standalone pages. Native dialogs preserve keyboard focus. There is no custom cursor, scroll hijacking, sound, tracking script, third-party font request, or skill-percentage chart. Light and dark modes, a command menu, Chinese and English content, and a motion toggle are ordinary controls, not Easter eggs.

05 / Edit & deploy

Public content lives in content/site.mjs. Design tokens live in assets/css/style.css. Run npm run build to regenerate the static pages; no package installation is required. The repository root or the generated dist/ directory can be served as static files. GitHub Pages supplies hosting; all computation described here happens in the browser.
